Dressmaker Commissions & Clients Guide

Townsfolk in Dressmaker (Steam / Free Lives) hire you for commissions: measure, design to their taste, craft within budget, and deliver. This page is the loop guide — systems deep-dives live on linked pages.

TL;DR — Read brief → design to tags → budget → craft → deliver

  1. Open the commission and note style targets, budget, occasion.
  2. Measure / fit.
  3. Sketch + preview style tags before buying fabric → Fabrics.
  4. Cut on grain → sew → decorate.
  5. Deliver; confirm acceptance / payout.
  6. Prefer finishing a client chain you started before juggling too many new stories.

Commission brief anatomy

Element Player job
Style words / tag targets Design + fabric until tags clear
Budget Cloth + trim must fit
Occasion / event context Silhouette + decoration vibe
Deadline / calendar pressure Don’t idle mid-chain if timed

Measurements & fit

Commissions typically start with client measurements so the pattern fits that townsfolk body. Follow the on-screen measurement prompts in your build — exact click order can vary by patch.

Tip Why
Complete measurement prompts before shopping Prevents rebuilds
Re-check brief after measuring Targets still govern tags/budget
Preview on mannequin Catches silhouette mistakes early → Pattern

Client chains vs event sets

Track What “done” means Achievement angle
Named client major commissions Finish that character’s chain Per-client trophies
Event / occasion dress sets Complete every dress for the event, not one centerpiece Event trophies
Pigeon deliveries Separate order track Own achievement

These tracks are not automatic substitutes for each other. Details → Achievements.

Pigeon orders

Some commissions arrive via pigeon. They form their own completion track for the “birds/frock” style achievement. Don’t assume finishing main clients covers them.

Pillar Guide

Failure modes & recovery

Failure Recovery
Low quality Audit grain first, then sewing
Wrong vibe Retag via pattern/fabric samples
Over budget Simplify cloth/trim; avoid accessory spam
Abandoned chain Return before starting too many new clients

Sabotage note

Steam’s blurb says you can satisfy or sabotage townsfolk. Treat sabotage as an alternate path — not day-1 play. Learn clean deliveries first; a dedicated sabotage walkthrough is out of scope for this page.

FAQ

How do I know delivery succeeded?
Watch for client try-on, dialogue, payout, or unlock signals on your build. If nothing unlocks, the dress may not have been accepted.

Are client chains the same as event achievements?
No — track both if you’re completionist.

What are pigeon orders?
A separate delivery channel with its own completion achievement.

Should I start every available client at once?
Prefer finishing major chains you opened.

Where is the crafting help?
Open the Systems Hub.
