Dressmaker Fabrics & Style Tags

Use this page to pick materials for Dressmaker on Steam so style tags match the client without blowing the budget. This is the game guide — not a real fabric store.

TL;DR — Design first, sample, then buy

  1. Build the silhouette in the sketchbook.
  2. Browse the shop, but drag fabric samples into the sketchbook before purchasing.
  3. Tags appear from fabric + pattern together (dev-described workflow).
  4. Compare tags to the commission brief.
  5. Buy only what clears tags and leaves room for trim/mistakes.

How style tags work

Developer guidance (itch/devlog era, concept still cited by guides): tags show in the sketchbook when you combine dress pattern choices with fabric samples. Fabric alone is not enough.

Step Action
1 Choose neckline/bodice/sleeves/skirt (pattern choices)
2 Drag candidate fabric samples into the sketchbook
3 Read resulting tags / bars
4 Adjust pattern or fabric until commission targets clear
5 Purchase

FAQ

Do tags come from fabric alone?
No — fabric plus pattern, previewed via samples in the sketchbook.

Are there only five fabrics?
Steam names five examples. The shop contains many more variants.

How do I preview before buying?
Drag samples into the sketchbook design.

What if I bought the wrong bolt?
Check whether your build allows undo; otherwise redesign with a matching sample or absorb the cost and move on.

Does quality replace tags?
No. Clients evaluate style match and budget alongside construction quality.
